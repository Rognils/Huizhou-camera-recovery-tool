# Changelog

## [2.0] - 2025-10-21
### Key Improvements
- **Proper Logging System** — Replaced `print()` statements with structured logging for improved debugging and control.
- **Font Caching** — Avoids repeated file I/O when loading fonts, improving performance.
- **Better Error Handling** — Added robust exception handling across all key functions.
- **Improved Argument Parsing** — Added a custom crop parser with validation for safer input handling.
- **Enhanced Code Readability** — Clearer variable names, consistent formatting, and comprehensive docstrings.
- **Safer File Operations** — Proper resource management and cleanup to prevent file handle leaks.
- **Documentation & Examples** — Added detailed help text and usage examples for easier understanding.
- **Type Hints** — Full type annotations for better IDE support and documentation.
- **Robust Frame Handling** — Improved fallback logic for image decoding and processing.
- **Consistent Code Style** — Fully PEP8-compliant with consistent spacing and structure.
